What is built in

Two rules, three ways to be told, one endpoint

Mismatch rule

Raises an alert whenever expected and actual do not match, and reports the gap.

Late-detection rule

Flags errors found after your limit, which you can set from 1 to 365 days. The default is 14.

Slack alerts

Post alerts to a channel through a webhook you control.

Email alerts

Claude triage

One JSON endpoint

How it works

What happens to every event

  1. The record arrives

    AEROS compares what the control expected with what actually happened, straight away.

  2. A mismatch is flagged

    If the amounts differ, an alert is raised with a severity, not at month end.

  3. The lag is measured

    The days between the error occurring and someone finding it, checked against your limit.

  4. The agent suggests where to look

    Likely causes, business impact and next steps. Rules only in dry-run, Claude in live mode.

  5. A person reviews it

    The agent only analyses and recommends. It never changes data.

Questions

Frequently asked questions

Does the demo send alerts or call an AI?

No. The demo always runs in dry-run mode, which uses rule-based triage only. Nothing is sent to Slack or email and no AI model is called.

Can the AI agent change my data?

No. The agent only analyses events and recommends where to look. A person reviews every alert.

What does an event look like?

Each event has an id, a process name, the expected and actual amounts, the date the error occurred and the date it was detected. The curl example in the API section shows one.

How is the detection lag measured?

It is the number of days between the date the error occurred and the date it was detected. If that is longer than your limit, the event is flagged as found late. The limit defaults to 14 days and can be set from 1 to 365.

What do I need to turn on live mode?

Set a token on the server and send it as a bearer token with each request. Live mode then adds Claude triage and, if you configure them, Slack or email alerts. Without the token, live mode is disabled.

How many events can I send at once?

Up to 200 events in a single request, within a body limit of about 100 KB.
